### ① AST解析時のIndentationError

`inspect.getsource()` はクラスメソッドのソースを取得するため、先頭にクラス階層分のインデントが残ります。

そのまま `ast.parse()` に渡していたため、構文解析に失敗していました。

- 修正：`textwrap.dedent(source)` を通してから解析する。
- `textwrap` のインポートも追加済みです。

### ② 保存成功を確認するテストのFAIL

テスト用ヘルパーが、単一の真偽値 `True` まで `side_effect` に渡していました。

Python 3.8の `unittest.mock` では、`side_effect=True` は正常な戻り値指定ではありません。今回の `TypeError: 'bool' object is not an iterator` は、このモック設定が原因です。

- 単一の真偽値：`return_value` を使用
- 複数回の結果を指定するリスト・タプル：`side_effect` を使用

このように使い分けるよう修正しました。
