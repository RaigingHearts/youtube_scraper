```python

(total_threads_expected +
```

こちらも現在の第2引数：

```python
(total_threads_expected +
 total_replies_expected) if comment_threads_completed else None,
```

次のように変更してください。

```python
(total_threads_expected +
 total_replies_expected)

else None,
```

これで、返信取得エラーなどによってページ処理を途中で打ち切った場合も、不完全な総数を確定値として通知しません。
