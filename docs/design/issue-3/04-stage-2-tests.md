# Issue #3：Stage 2 テスト仕様 — 進捗表示と通知のキュー経由化

## 1. 進捗更新
最新値への置換、マーカー重複登録防止、マーカー消費後の再登録、同時更新時の競合防止、更新取りこぼし防止、Tkinterオブジェクト非包含を確認する。

## 2. 通知
info/warning/error、タイトル・本文、FIFO順、意図しない破棄がないこと、Tkinterオブジェクト非包含を確認する。

## 3. GUI要求処理
進捗・通知をメインスレッドで処理する。未知の要求種別や1要求の例外でポーリング全体が停止しない。処理上限と混在要求を確認する。

## 4. スレッド境界
ワーカーからウィジェット、after()、tk_notificationsを直接呼び出さず、GUI更新がメインスレッドで実行されることを確認する。

## 5. 取得処理統合
モックAPIで進捗、通知、完了結果、保存先情報を確認する。GUI側が戻り値を回収し、最終進捗と例外時の通知を正しく処理する。

## 6. GUI統合・完了条件
実際のTkイベントループで長時間処理中の応答性、進捗表示、通知表示を検証する。Python 3.8.10、unittestを使用する。
