YouTubeコメント取得ツール
このプログラムは、YouTube Data API を利用して、指定されたYouTube動画のコメントおよび動画情報を取得し、JSON形式で保存するGUIツールです。

概要
Windows 7、Python 3.8.10、VS Code 1.70.2 環境での動作を想定して開発されています。Tkinter を用いた直感的なGUIで操作でき、取得したデータは整形されたJSONファイルとして保存されます。APIエラーやプログラムエラーはログファイルに記録され、専用のウィンドウで確認できます。

機能
GUI操作: Tkinter を使用したユーザーフレンドリーなインターフェース。

動画情報取得: YouTube動画のURLまたは動画IDから、動画タイトル、投稿者（チャンネル名）などの基本情報を取得し、RawデータとしてJSONファイルに保存。

コメント取得: 動画のすべてのコメント（スレッドと返信）をAPIから取得し、RawデータとしてJSONファイルに保存。

プログレスバー: コメント取得の進行状況をリアルタイムで表示。

コメント取得上限確認: プログラムが設定したコメント取得上限を超えそうな場合に、ユーザーに継続の意思を確認。

APIキー管理: APIキーは初回起動時にポップアップダイアログで入力し、設定ファイルに暗号化して保存。

エラーログ: APIエラーやプログラムエラーを trace.log ファイルに記録。

ログ表示: ログファイルの内容を別ウィンドウで表示、またはテキストエディタで開くことが可能。

JSONファイル確認: 取得完了後、保存されたJSONデータファイル（動画情報とコメントデータ）をデフォルトのアプリケーションで開いて確認。

ファイル保存場所: すべてのデータファイル、ログファイル、設定ファイルはプログラムと同じフォルダ内に保存。

モジュール構成
このアプリケーションは、汎用的な機能をモジュールとして切り出す計画に基づき、以下のモジュールで構成されています。

logger_config.py: ロギング機能を提供します。（旧 log_manager.py）

settings_manager.py: APIキーなどの機密性の高い設定を安全に管理します。

file_operations.py: ファイルやディレクトリの基本的な操作（ファイルを開くなど）を提供します。（旧 utils.py から切り出し）

json_data_handler.py: JSONデータの保存など、JSONファイル操作を提供します。（旧 utils.py から切り出し）

youtube_utils.py: YouTube関連のユーティリティ（動画ID抽出など）を提供します。（旧 utils.py から切り出し）

youtube_api_client.py: YouTube Data APIとの連携を扱います。

tk_app_settings.py: Tkinterアプリケーションの設定管理（APIキープロンプトなど）を扱います。

tk_async_tasks.py: Tkinterアプリケーションにおける非同期タスクの実行と進捗更新を扱います。

tk_notifications.py: Tkinterアプリケーションにおけるメッセージボックスやダイアログ表示を扱います。

main.py: アプリケーションのメインロジックとGUIの構築を行います。

動作環境
OS: Windows 7

Python: 3.8.10

VS Code: 1.70.2

必要なライブラリのインストール
プログラムを実行する前に、以下のPythonライブラリをインストールする必要があります。

VS Codeのターミナル（Ctrl+Shift+@）で、プロジェクトのルートディレクトリに移動し、以下のコマンドを実行してください。

pip install google-api-python-client cryptography

注意: cryptography ライブラリのインストールで問題が発生した場合（特にWindows 7環境）、PyInstallerのビルド時にも同様の問題が発生する可能性があります。その際は、pip install cryptography==3.4.8 のように、少し古いバージョンを試すことを検討してください。また、Visual C++ Redistributableがインストールされていることを確認してください。

APIキーの準備
このプログラムを使用するには、Google Cloud Console で YouTube Data API v3 のAPIキーを取得する必要があります。

Google Cloud Console にアクセス:
ウェブブラウザで Google Cloud Console にアクセスし、Googleアカウントでログインします。

新しいプロジェクトを作成:
画面上部のプロジェクトセレクタで「プロジェクトの選択」をクリックし、「新しいプロジェクト」を選択します。
プロジェクト名を入力し、作成します。

YouTube Data API v3 を有効化:
作成したプロジェクトが選択されていることを確認します。
ナビゲーションメニューから「APIとサービス」>「ライブラリ」に移動します。
検索バーで「YouTube Data API v3」と検索し、表示されたAPIを選択して「有効にする」をクリックします。

APIキーの作成:
ナビゲーションメニューから「APIとサービス」>「認証情報」に移動します。
「認証情報を作成」をクリックし、「APIキー」を選択します。
APIキーが生成され、表示されます。このキーをコピーしてください。

APIキーの制限設定（推奨）:
セキュリティのため、生成されたAPIキーに制限を設定することを強く推奨します。
APIキーのリストで作成したキーをクリックします。
「アプリケーションの制限」で「なし」から「IPアドレス」を選択し、プログラムを実行するPCのIPアドレスを追加します。
「APIの制限」で「キーを制限」を選択し、「YouTube Data API v3」のみを許可するように設定します。
設定を保存します。

使用方法

プロジェクトの準備
このプログラムのファイルを、任意のフォルダ（例: N:\Documents\[App] 名前をつけて保存\python_scripts\get-youtube_comments）に配置します。

VS Codeで、このフォルダをプロジェクトルートとして開きます。
VS Codeの「ファイル」>「フォルダーを開く...」を選択し、get-youtube_comments フォルダを選択します。

VS Codeのターミナル（Ctrl+Shift+@）が、プロジェクトルートに設定されていることを確認します。もし設定されていない場合は、cd N:\Documents\[App] 名前をつけて保存\python_scripts\get-youtube_comments のように移動してください。

ヒント: 常にプロジェクトルートでターミナルを開くようにするには、VS Codeのワークスペース設定ファイル（.vscode/settings.json）に以下の設定を追加します。

{
    "terminal.integrated.cwd": "N:\\Documents\\[App] 名前をつけて保存\\python_scripts\\get-youtube_comments"
}

(パスは実際のフォルダパスに合わせてください。バックスラッシュは二重に記述します。)

プログラムの実行
main.py ファイルをVS Codeで開きます。

VS Codeの右上にある「実行」ボタン（緑色の再生アイコン）をクリックするか、F5キーを押します。
または、ターミナルで python main.py コマンドを実行します。

APIキーの設定
プログラムの初回起動時、またはAPIキーが設定されていない場合、YouTube Data APIキーの入力を求めるポップアップダイアログが表示されます。
有効なAPIキーを入力し、「OK」をクリックしてください。入力されたAPIキーは暗号化され、youtube_scraper-settings.json ファイルに保存されます。

コメントの取得
GUIの「YouTube URL」フィールドに、コメントを取得したいYouTube動画のURLを入力します。

「URLから動画IDを解析」ボタンをクリックすると、URLから動画IDが抽出され、「動画ID」フィールドに自動入力されます。

動画IDを直接知っている場合は、「動画ID」フィールドに直接入力することも可能です。

「コメント取得開始」ボタンをクリックします。

コメントの取得が開始され、プログレスバーと取得コメント数が更新されます。

APIクォータ制限に達した場合や、設定されたコメント取得上限を超えそうな場合、確認ダイアログが表示されます。指示に従って操作してください。

取得データの確認
コメント取得が完了すると、プログラムと同じフォルダ内に以下のJSONファイルが生成されます。

video_info_raw_{動画ID}.json: 動画情報のRawレスポンスデータ。
comments_raw_{動画ID}.json: コメントスレッドのRawレスポンスデータ。
channel_info_raw_{チャンネルID}.json: チャンネル情報のRawレスポンスデータ。

GUIの「取得完了JSONファイルを開く」ボタンが有効になります。これをクリックすると、コメントデータファイル、動画情報ファイル、またはチャンネル情報ファイルを開くかを選択するダイアログが表示され、選択したファイルがOSのデフォルトアプリケーションで開かれます。

ログの確認
GUIの「ログを表示」ボタンをクリックすると、trace.log ファイルの内容が別ウィンドウで表示されます。これにより、APIエラーやプログラムエラーの詳細を確認できます。

注意事項とトラブルシューティング
APIクォータ: YouTube Data APIにはクォータ制限があります。大量のコメントを取得しようとすると、クォータを使い切ってしまう可能性があります。クォータ制限に達した場合、プログラムはエラーをログに記録し、ユーザーに通知します。しばらく待ってから再試行してください。

Python/OSの互換性: Windows 7とPython 3.8.10の組み合わせは古い環境であり、一部のライブラリ（特にcryptography）の最新バージョンとの互換性に問題が生じる場合があります。もしインストールや実行で問題が発生する場合は、上記「必要なライブラリのインストール」セクションのヒントを参考にしてください。

PyInstallerでのビルド: プログラムを単一の実行可能ファイルに変換する場合、PyInstaller を使用します。ビルド方法については、このドキュメントの上部にある「VS Codeでのプログラムのビルドと実行」セクションを参照してください。ビルド環境の互換性により、.exe ファイルの作成が困難な場合があります。
